# ConnectSphere – Cultural Matching App

ConnectSphere is a cultural matching application that helps users discover people with similar cultural interests and backgrounds.

## Features

- Cultural profile matching
- Recommendation engine using cosine similarity
- SQLite database integration
- Google Maps API integration
- Interactive Streamlit interface

## Tech Stack

- Python
- Streamlit
- SQLite
- Google Maps API
- Cosine Similarity

## Project Goal

The project aims to help users discover culturally compatible connections through data-driven recommendations.

pip install -r requirements.txt
